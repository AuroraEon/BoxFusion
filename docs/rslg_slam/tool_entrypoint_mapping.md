# RSLG-SLAM Tool Entrypoint Mapping

This document is a read-only static mapping from the current scattered tool scripts to a future canonical `tools/rslg_pipeline/` architecture. Task25e did not move, delete, rename, rewrite, or migrate code, and it did not create `tools/rslg_pipeline/` modules.

`BoxFusion` is only the historical repository path. The project name is RSLG-SLAM. Layer 1 is the World Model Layer; Stage-A is a historical implementation entrypoint such as `stage_a_demo.py`.

## Future Canonical Targets

| Future target | Intended role |
| --- | --- |
| `tools/rslg_pipeline/build_world_model.py` | Canonical wrapper for World Model Layer runs and provenance checks. |
| `tools/rslg_pipeline/build_stable_maps.py` | Stable occupancy map generation/validation, with Layer 2 generation and Layer 3 consumption clearly separated. |
| `tools/rslg_pipeline/build_vertical_connectors.py` | Vertical connector artifacts and cross-floor topology exports. |
| `tools/rslg_pipeline/build_object_interfaces.py` | Object candidate, query, approach, and object-route interface exports. |
| `tools/rslg_pipeline/build_route_contracts.py` | Room/connector/object route contracts and invariant checks. |
| `tools/rslg_pipeline/validate_artifacts.py` | JSON/schema/protected-path/no-rerun/no-runtime static validation. |
| `tools/rslg_pipeline/export_runtime_inputs.py` | Runtime-facing input bundles without claiming runtime success. |
| `tools/rslg_pipeline/artifact_registry.py` | Shared artifact path registry and protected-path policy. |
| `tools/rslg_pipeline/common.py` | Shared small utilities. |
