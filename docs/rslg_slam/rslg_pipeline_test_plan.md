# RSLG-SLAM Pipeline Test Plan

This is a minimal future test plan for safe migration into `tools/rslg_pipeline/`. Task25e does not implement these tests and does not execute pipeline, runtime, Gazebo, RViz, Nav2, AMCL, or World Model Layer reruns.

## Test Groups

| Test group | Layer | Purpose | Future target |
| --- | --- | --- | --- |
| `json_load_validation` | all layers | Validate all created/modified JSON docs/manifests load with Python json.load. | `tools/rslg_pipeline/validate_artifacts.py` |
| `protected_path_non_modification` | all layers | Record and compare stat metadata for protected baselines and canonical outputs. | `tools/rslg_pipeline/validate_artifacts.py` |
| `world_model_no_rerun_static_tasks` | Layer 1: World Model Layer | Ensure documentation-only tasks do not launch Stage-A or World Model Layer. | `tools/rslg_pipeline/validate_artifacts.py` |
| `stable_occupancy_map_product_checks` | Layer 2: Formal Artifact Layer / Layer 3: Navigation Interface Layer | Check stable occupancy map references are derived RSLG-SLAM products and load as expected. | `tools/rslg_pipeline/build_stable_maps.py` |
| `stable_map_object_coordinate_alignment` | Layer 2: Formal Artifact Layer | Compare project, no-y-flip, and y-flip transforms for object, room, topology, and connector references without regenerating map or approach geometry. | `tools/rslg_pipeline/stable_map_object_alignment_audit.py` |
| `vertical_connector_invariants` | Layer 2: Formal Artifact Layer | Protect connector ids, floor transition edge truth, and route chain invariants. | `tools/rslg_pipeline/build_vertical_connectors.py` |
| `object_interface_invariants` | Layer 2: Formal Artifact Layer / Layer 3: Navigation Interface Layer | Protect obj_175 curtain smoke-test contract and generated approach candidate semantics. | `tools/rslg_pipeline/build_object_interfaces.py` |

| `no_external_gt_manual_source` | Layer 0: Input Layer / Layer 1: World Model Layer / Layer 2: Formal Artifact Layer | Verify artifact provenance excludes forbidden source types. | `tools/rslg_pipeline/validate_artifacts.py` |
| `no_runtime_launch_static_validation` | Layer 4: Runtime Validation Layer | Static validation tasks must not start ROS/Gazebo/RViz/Nav2/AMCL. | `tools/rslg_pipeline/validate_artifacts.py` |

## Required Guardrails

- JSON schema/load validation must run on created or modified JSON files before a migration task is complete.
- Protected paths must be checked before and after any migration task. This includes the 00824 reference baseline and the 00843 `clean_rerun` canonical outputs.
- Documentation-only and static validation tasks must prove that the World Model Layer / Stage-A was not rerun.
- Static validation tasks must prove that Gazebo, RViz, Nav2, AMCL, and runtime demos were not launched.
- Stable occupancy maps must remain RSLG-SLAM-derived products, not external GT occupancy maps, semantic floorplans, room masks, or runtime costmaps.
- Vertical connector checks must preserve `vt_1_centerline_e001` as the real floor transition edge and must not treat `vt_1_centerline_e003` as that edge.
- Object interface checks must preserve the validated `curtain in room_14 on floor_2` smoke-test contract for `obj_175` and `generated_ring_037`, with `object_centroid_navigation_used` false.
- Route contract checks must preserve the current route truth: `room_2 on floor_1 -> room_3 on floor_1 -> vt_1 / vc_vt_1 connector -> room_7 on floor_2 -> room_13 -> room_14`.
- Task25i adds dry-run wrapper validation for route-contract planning in `tools/rslg_pipeline/build_route_contracts.py`; this check must remain manifest-aware and must not generate route contracts.
- Task25j adds route contract stub generation for `cross_floor_room` and `cross_floor_object`; validation must confirm stubs are marked non-final and do not generate A* routes, stable maps, object approach geometry, or runtime evidence.
- Task25k adds route contract stub schema validation in `tools/rslg_pipeline/route_contract_schema.py`; validation must check stub identity, safety flags, route/transition truth, object truth, forbidden claims, and stage_outputs independence without launching runtime systems or generating routes.
- Task25l adds route contract stub to candidate promotion dry-run validation in `tools/rslg_pipeline/route_contract_promotion.py`; validation must check schema-validated stubs, promotable fields, blocked Layer 2 dependencies, candidate-preview flags, and claim-boundary protection without writing final route contracts.
- Task25n adds candidate route contract schema dry-run validation in `tools/rslg_pipeline/candidate_route_contract_schema.py`; validation must check promotion candidate previews for future candidate identity, route truth, object truth, claim boundary, and blocked Layer 2 dependencies without writing final candidate contracts, requiring historical `stage_outputs/`, generating A* routes, or creating runtime artifacts.
- Task25o adds Layer 3 boundary review in `tools/rslg_pipeline/layer3_boundary_review.py`; validation must confirm the Layer 3 dry-run chain is complete enough to pause, final contracts remain blocked by Layer 2 artifacts, and the next phase returns to Layer 2 formal artifact regeneration.
- Task25p adds Layer 2 vertical connector/topology dry-run validation in `tools/rslg_pipeline/build_vertical_connectors.py`; validation must confirm `all`, `vertical_connectors`, `connector_graph`, and `cross_floor_topology` dry-runs produce preview-only reports, preserve `vt_1_centerline_e001` as the transition edge, do not require historical `stage_outputs/`, and do not generate final formal artifacts, connector geometry, topology, routes, or runtime artifacts.
- Task25q adds Layer 2 vertical connector/topology dry-run schema validation in `tools/rslg_pipeline/vertical_connector_schema.py`; validation must check Layer 2 metadata, validated connector truth, preview-only future artifact scopes, blocked fields, downstream Layer 3 dependency relationships, and forbidden claims without requiring historical `stage_outputs/` or generating final formal artifacts.
- Task26 adds candidate Layer 2 vertical connector/topology artifact generation in `tools/rslg_pipeline/build_vertical_connectors.py`; validation must confirm the candidate vertical connector, connector graph, and cross-floor topology artifacts are marked non-final, preserve `vt_1_centerline_e001` as the transition edge, keep `vt_1_centerline_e003` non-transition, use validated milestone truth rather than current Layer 1 rerun outputs, avoid historical `stage_outputs` dependence, and pass `tools/rslg_pipeline/vertical_connector_schema.py` in candidate-artifact or auto mode.
- Task27 adds stable occupancy map dry-run, metadata-only candidate package generation, and schema validation in `tools/rslg_pipeline/build_stable_maps.py` and `tools/rslg_pipeline/stable_map_schema.py`; validation must confirm the dry-run and candidate package are Layer 2, non-final, stage_outputs-independent, and do not generate map pixels, PGM, map_server YAML, runtime costmaps, routes, or runtime validation artifacts. The candidate package must keep stable occupancy maps distinct from semantic floorplans, room masks, runtime costmaps, external GT maps, and simulator navmeshes.
- Task28 adds object interface dry-run, candidate package generation, and schema validation in `tools/rslg_pipeline/build_object_interfaces.py` and `tools/rslg_pipeline/object_interface_schema.py`; validation must confirm the dry-run and candidate artifacts are Layer 2, non-final, stage_outputs-independent, generated from validated milestone truth rather than a current World Model Layer rerun, and do not generate real object query resolution, approach geometry, routes, runtime inputs, or object-navigation runtime evidence. The object approach candidate must keep `object_centroid_navigation_used` and direct centroid-goal use false.
- Task29 adds Layer 2 candidate integration review and Layer 3 readiness validation in `tools/rslg_pipeline/layer2_candidate_integration_review.py`; validation must confirm vertical connector/topology, stable map package, and object interface candidates are all present, schema-valid, non-final, and consistent with route/object truth before `cross_floor_room` and `cross_floor_object` are marked ready for Layer 3 candidate route contract generation.
- Task30 adds candidate route contract generation from Layer 2 candidate artifacts in `tools/rslg_pipeline/build_route_contracts.py` and actual contract validation in `tools/rslg_pipeline/candidate_route_contract_schema.py`; validation must confirm `cross_floor_room` and `cross_floor_object` contracts are Layer 3, non-final, generated from candidate Layer 2 dependencies, dependency-scoped by route kind, and do not generate final route contracts, real A* routes, executable waypoints, runtime inputs, runtime artifacts, map pixels, connector geometry, or object approach geometry.
- Task31 adds route plan dry-run preview generation in `tools/rslg_pipeline/build_route_plans.py` and validation in `tools/rslg_pipeline/route_plan_schema.py`; validation must confirm `cross_floor_room` has only floor-room and vertical-transition segment previews, `cross_floor_object` additionally has an object approach segment preview, both preserve `vt_1_centerline_e001` and `vt_1_centerline_e003`, and neither generates real A* routes, waypoints, executable routes, runtime inputs, runtime artifacts, map pixels, connector geometry, or object approach geometry.
- Task33 adds final artifact boundary review and canonical output planning in `tools/rslg_pipeline/final_artifact_boundary_review.py`; validation must confirm the report is review-only, proposes a canonical output root separate from task evidence, identifies candidate-to-final regeneration decisions, keeps real route generation blocked until final Layer 2 artifacts exist, and does not create canonical directories, final artifacts, routes, waypoints, map pixels, connector geometry, object approach geometry, runtime input packages, or runtime artifacts.
- Task34 adds final Layer 2 minimal generation planning in `tools/rslg_pipeline/final_layer2_generation_plan.py`; validation must confirm the report is plan-only, defines a dependency DAG rather than a flat list, identifies Layer 1 source requirements, final Layer 2 artifact specs, promotion/regeneration policy, canonical write plan, validation sequence, real-route unblock conditions, and risks while creating no canonical directories, final artifacts, route contracts, route plans, A* routes, waypoints, map pixels, connector geometry, object approach geometry, runtime input packages, or runtime artifacts.
- Task36b audits canonical floor-map raster orientation and world-to-grid consistency using the project, no-y-flip, and y-flip transforms. Validation must confirm route-relevant room and connector references use the same convention as object coordinates, the debug overlay remains evidence-only, canonical Layer 2 artifacts remain unchanged, and no route, waypoint, PGM, map-server YAML, connector geometry, or object approach geometry is generated.
- Route-kind-specific dependency scoping must remain enforced: `cross_floor_room` requires stable occupancy maps, vertical connector artifacts, and cross-floor topology only; `cross_floor_object` additionally requires object query resolution and object approach candidate artifacts.
- Runtime input compatibility checks must remain static unless the task explicitly asks for runtime launch evidence.
- Source-boundary checks must fail closed on external GT floorplans, external GT occupancy maps, manual stair centerlines, manual object target poses, and simulator navmesh as world-model sources.
