# RSLG-SLAM Project Contract

RSLG-SLAM is the project name. The repository still lives at `/home/ws/workspace/BoxFusion`, but BoxFusion is only the historical repository path and should not be used as the project name in new project-facing documentation.

RSLG-SLAM is a rich-semantic, light-geometry indoor world-modeling system. In the dataset setting, scene-specific inputs are RGB images, depth images, and provided camera poses. The system uses the provided poses and must not claim dataset-side SLAM or localization accuracy from those inputs.

## Core Contract

RSLG-SLAM builds semantic-topological indoor world models from RGB-D plus pose. Its formal artifacts may then support downstream routing, interface export, and runtime validation.

For real-world deployment, describe the system as:

`SLAM/localization front-end + RSLG-SLAM semantic-topological world-modeling backend + downstream routing/execution interface`

The SLAM/localization front-end is outside the dataset-side claim unless explicitly implemented and validated in a separate task.

## Allowed Inputs

- RGB images.
- Depth images.
- Provided camera poses in the dataset setting.
- Pipeline products derived from RGB-D plus pose through the World Model Layer and formal artifact builders.

## Forbidden World-Model Sources

- External ground-truth floorplan.
- External ground-truth occupancy map.
- Manually drawn stair or connector centerline.
- Manually specified object target pose.
- Simulator navmesh.

Navigation resources may be generated by downstream builders, but they must be RSLG-SLAM pipeline products derived from RGB-D plus pose through the World Model Layer and formal artifact builders.

## Claim Boundaries

RSLG-SLAM does not claim dense reconstruction, physical stair climbing, footstep planning, gait control, contact dynamics, AMCL success, real robot stair climbing, or a full object-navigation benchmark.

Validated runtime or smoke-test evidence must be stated at its actual level. For example, task24h validated visual-kinematic cross-floor tracking, not physical stair climbing, Nav2, AMCL, gait, contact dynamics, or footstep planning.
